## 推荐阅读路线

1. 先读前言和第一章，理解作者为什么不把导论写成软件操作手册。
2. 第二章只要求建立从计算模型到软硬件系统的纵向地图，不必第一次就记住全部术语。
3. 第三章是全书核心，重点掌握三个基本问题、三种学科形态、典型方法和基本工作流程。
4. 第四章需要区分长期有效的学习原则与带有时代背景的具体培养方案。
5. 第五章用布尔代数实际体会形式化、公理化和演绎推理。

## OCR 说明

原 PDF 是扫描件，OCR 全文以 UTF-8 保存，并使用 `===== PDF 第 NNN 页 =====` 标记物理页码。292 页均完成识别，没有 OCR 失败页。

正文段落整体可读，但公式、逻辑符号、集合运算符、上下标、表格和图示可能存在误识别。精确引用或学习第五章时，应回到 PDF 核对原页。

本书第三版出版于 2004 年，部分产业判断、技术名称、期刊情况和课程设置已经具有明显的时代性。阅读时应把它们视为历史材料；全书关于计算、抽象、基础知识和科学方法的讨论更具有长期价值。
