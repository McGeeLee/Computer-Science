# 《计算机科学导论》第四版：章末关键术语与缩写

这份笔记把第四版 20 章的章末“关键术语”压缩成一张缩写知识地图，并结合书末印刷页 434–435 的缩略语表校正英文全称。目标不是机械背单词，而是看到缩写时能判断它属于计算机系统的哪一层、解决什么问题。

> 版本说明：第三版与第四版前 18 章的知识主干基本相同，因此这份词汇表也可作为第三版的补充。第四版新增第 19 章“社交媒体导论”和第 20 章“社会和道德问题”。原 PDF 的扫描文字层存在少量误识别，本笔记已经校正 `GUI`、`SSH`、`Rivest-Shamir-Adleman` 等明显错误。

## 四、第三档：知道是什么、需要时会查即可

| 类别 | 缩写 | 说明 |
| --- | --- | --- |
| 旧式介质 | `CD-ROM`、`CD-R`、`CD-RW`、`WORM` | 了解存储介质演进即可 |
| 历史平台与编码 | `MS-DOS`、`EBCDIC` | 在遗留系统或历史材料中出现 |

| 历史密码标准 | `DES` | 已不适合保护现代敏感数据，重点理解其历史地位 |
| 传统语言 | `FORTRAN`、`COBOL`、`LISP`、`PROLOG` | 在科学计算、金融遗留系统或 AI 历史中仍有意义 |

## 五、容易混淆的缩写组

### RAM、ROM、DRAM、SRAM

`RAM` 是可随机访问的工作存储器总称；现代主存通常使用 `DRAM`，CPU 高速缓存常使用更快、更贵的 `SRAM`。`ROM` 强调内容不按普通方式频繁改写。

### IP、TCP、UDP、HTTP

`IP` 负责跨网络传递数据报；`TCP` 和 `UDP` 位于传输层；`HTTP` 是运行在传输服务之上的应用层协议。它们不是相互替代的同级协议。

### DNS、URL、HTTP、HTML

`DNS` 解决“名字对应什么地址”，`URL` 描述“资源在哪里”，`HTTP` 规定“怎样请求和响应”，`HTML` 描述“网页内容怎样组织”。

### DBMS、RDBMS、SQL

`DBMS` 是数据库管理系统的总称；`RDBMS` 是采用关系模型的数据库管理系统；`SQL` 是操作关系数据库的语言，不是数据库本身。

### AES、RSA、SHA

`AES` 是对称加密算法；`RSA` 是非对称密码系统；`SHA` 是散列算法。散列不是加密，因为它通常不设计为可逆。

### MAC 的两个含义

在网络中，`MAC` 可以表示 Media Access Control（媒体访问控制）；在密码学中，也可以表示 Message Authentication Code（消息认证码）。必须根据上下文判断。

### ADT、BST、FIFO、LIFO

`ADT` 是只规定操作和行为的抽象数据类型；`BST` 是具有有序性质的二叉搜索树；`FIFO` 描述队列的先进先出顺序；`LIFO` 描述栈的后进先出顺序。

## 七、记忆方法

先记“类别和作用”，再记英文全称。看到缩写时按下面的路径定位：

```text
CPU / RAM / OS
        ↓ 程序运行环境
IP / TCP / DNS / HTTP
        ↓ 网络通信
SQL / DBMS
        ↓ 数据组织
AES / RSA / SHA
        ↓ 安全保护
```

第一档需要做到不查资料也能解释；第二档在进入相应课程或项目时掌握；第三档只需保留印象并知道去哪里查询。英文全称不是孤立考点，能说清缩写所处的层次、输入输出和用途才算真正理解。
