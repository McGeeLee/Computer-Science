## 本书定位

这是一本百科全书式的计算机科学入门教材，重点是用较少数学细节建立全领域知识地图，而不是把某个主题讲到专业课程的深度。全书可分为五条主线：

```text
数据的表示与运算       第2～4章
计算机硬件与通信       第5～6章
计算机软件             第7～10章
数据组织与抽象         第11～14章
高级主题               第15～18章
```

第 1 章负责总览这些主线。作者在前言中把第 1～8 章视为理解后续内容的基础；第 9～14 章可按学习时间选择，第 15～18 章适合根据方向选读。

## 推荐使用方式

可以先看总结建立知识地图，再根据兴趣和用途细读原书。每章建议完成一个“解释闭环”：

1. 用自己的话说出这一章处理的对象和核心问题。
2. 画出关键层次、数据流或组成关系。
3. 手算、跟踪或实现一个小例子。
4. 用边界情况检查自己的理解。
5. 需要准确公式、位模式、协议字段或伪代码时回到 PDF。

第一次阅读可优先走 `1 → 2 → 3 → 5 → 7 → 8 → 11 → 12 → 17`；想理解互联网、数据库、安全或人工智能时，再分别深入第 6、14、16、18 章。

## OCR 与版本说明

原 PDF 是扫描件，没有可用文字层。OCR 全文使用 UTF-8 保存，并以 `===== PDF 第 NNN 页 =====` 标记物理页码。437 页全部完成识别，没有失败页，平均识别置信度约为 0.72。

普通中文段落整体可检索，但二进制位串、上下标、数学公式、真值表、流程图、程序代码和表格容易误识别。精确计算或引用时必须回到 PDF 核对。原书写于 2014 年，网络协议、操作系统版本、安全算法和人工智能现状等部分已经具有时代背景；基础模型仍有价值，现实状态应结合当前资料更新。
