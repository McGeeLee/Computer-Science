# 第5章：计算机组成

## 本章主线

本章把冯·诺依曼模型展开为 CPU、主存和输入输出三个子系统，并通过一台简单假想计算机说明指令如何真正执行。

## 三个子系统

- CPU：ALU 完成逻辑、移位和算术运算；寄存器保存当前操作数、地址和状态；控制单元协调执行。
- 主存：按地址访问字或字节。地址空间描述可寻址单元数量，存储层次在速度、容量和成本之间折中，高速缓存缩小 CPU 与主存的速度差距。
- 输入输出：连接键盘、显示器和外部存储等设备。设备速度与 CPU 差异很大，需要控制器、接口和同步机制。

总线或互连系统传递数据、地址与控制信号。寻址方式决定 CPU 如何指定内存和 I/O 设备。

## 指令周期

控制单元反复执行：根据程序计数器取指令，把指令放入指令寄存器并更新计数器；译码操作码和操作数；执行运算、访存、跳转或 I/O。程序的高级含义最终落在这组简单状态变化上。

## 体系结构取舍

CISC 倾向提供更复杂指令，RISC 倾向使用较简单、规则的指令。流水线让不同指令的阶段重叠以提高吞吐量，并行处理让多个处理单元同时工作。吞吐量提高不等于单条任务延迟按相同比例下降。

## 最小练习

选取一条“从内存取数并相加”的假想指令，逐周期记录 PC、IR、寄存器和内存的变化；再画出 CPU、主存和 I/O 之间的数据、地址、控制三类连接。
