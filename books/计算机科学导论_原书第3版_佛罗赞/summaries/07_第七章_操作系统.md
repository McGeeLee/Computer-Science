# 第7章：操作系统

## 本章主线

操作系统位于硬件与用户或应用程序之间，既提供方便的抽象，又协调有限资源。它不是单一功能，而是一组相互配合的管理器。

## 启动与演化

开机后，硬件先执行固件中的少量引导代码，再把操作系统核心装入内存，这就是自举。批处理、分时、个人计算、并行、分布式和实时系统的发展，反映了吞吐量、交互性、共享、可靠性和响应期限等不同目标。

## 主要组成

- 用户界面或系统调用接口：让人和程序请求系统服务。
- 内存管理器：分配和回收内存，并通过分页、虚拟内存等方式隔离进程、扩展可用空间。
- 进程管理器：创建、调度和结束进程，处理并发、同步、死锁与资源竞争。
- 设备管理器：屏蔽设备差异，协调缓冲、驱动和 I/O 请求。
- 文件管理器：组织持久数据，管理目录、权限和空间。

操作系统的核心矛盾是方便与效率、共享与隔离、公平与优先级之间的取舍。

## 版本提醒

书中 UNIX、Linux 和 Windows 的具体版本描述已经过时，但多用户、进程、虚拟内存、文件系统和设备抽象仍是理解现代桌面、移动、服务器和容器环境的基础。

## 最小练习

打开多个应用，画出进程、虚拟内存、文件和设备之间的关系；再跟踪“读取一个文件”涉及应用、系统调用、文件系统、设备驱动和存储设备的路径。
