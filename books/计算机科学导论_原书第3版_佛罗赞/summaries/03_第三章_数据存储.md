# 第3章：数据存储

## 本章主线

计算机把数字、文本、音频、图像和视频统一编码为位模式。关键不是背每个格式，而是理解“外部含义 → 编码 → 位模式 → 解码”的过程。

## 数字表示

- 无符号整数把全部位用于大小，范围从 0 开始。
- 符号加绝对值把一位用于符号，存在正零和负零，运算较麻烦。
- 二进制补码把符号与数值统一到模运算中，只有一个零，适合整数算术；固定位宽决定范围，越界会产生溢出。
- 浮点数把实数近似表示为符号、指数和尾数。规范化提高有效位利用率，但有限位宽意味着舍入、上溢和下溢。

位模式只有结合类型和位宽才有意义；同一串位可以被解释为不同数值。

## 其他数据

- 文本通过字符编码把字符映射到整数，再存为位。Unicode 解决跨语言字符集合问题。
- 音频从连续信号采样，再量化并编码。采样率影响时间分辨率，量化位数影响幅度精度。
- 光栅图存储像素，放大可能出现锯齿；矢量图存储几何描述，更适合缩放。
- 视频可看作随时间变化的图像序列，并常结合声音与压缩。

## 容易混淆

编码不是数据本身；精度也不等于准确度。增加位数可缩小量化误差，却不能修复采样方式、传感器或模型造成的问题。浮点数通常是近似值，不能直接套用实数的精确相等直觉。
