# Books

每本书使用一个独立目录，避免不同书籍的 PDF、OCR 和笔记互相混杂。

## 命名建议

- 默认使用 `书名_版本`，例如 `计算科学导论_第三版`。
- 同名不同作者时增加作者名，例如 `计算机程序的构造和解释_Abelson`。
- 文件名保持稳定；书籍加入 Git 后，尽量避免没有必要的反复改名。

## 每本书的最低内容

- `README.md`：书目信息、内容状态、页码索引和阅读路线；
- `summaries/00_全书导读.md`：全书目的、结构和适合的读法；
- `summaries/NN_章节名.md`：每章的核心问题、概念关系和检查题。

原始资料和 OCR 文本按实际情况放入 `source/` 与 `text/`。如果没有合法保存或传播完整资料的条件，可以只提交总结和个人笔记。

## 总结写作原则

1. 先说本章解决什么问题，再列概念和事实。
2. 展示概念之间的因果、层次或依赖关系。
3. 区分作者观点、事实陈述和整理者的补充判断。
4. 标出可能过时、存在争议或需要回原文核对的内容。
5. 用少量检查题验证是否真正理解，而不只是读过。
