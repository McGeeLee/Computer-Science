## 本书定位

这不是一本“再列一遍计算机术语”的导论，而是一本面向程序员的系统桥梁书。它把 C 程序一路向下连接到机器指令、处理器、缓存和虚拟内存，再向外连接到进程、文件、网络和并发。全书的主线可以概括为：

```text
程序怎样被表示和执行     第1～6章
程序怎样在系统上运行     第7～9章
程序怎样与外界和彼此交互 第10～12章
```

它关注的不是“如何设计一颗 CPU 或一个操作系统”，而是这些系统机制怎样影响程序的正确性、性能、安全性与可移植性。示例环境以 x86-64、Linux 和 C 为主。

## 推荐使用方式

可以先读总结建立地图，但这本书不能只靠总结学会。最有效的循环是“先看总结 → 带着问题读原章 → 编译或单步跟踪示例 → 做练习或实验 → 回写自己的解释”。遇到下列内容应回到原书：

- 位级运算、补码溢出、浮点舍入等需要精确推导的内容；
- 汇编、流水线、缓存和地址翻译图；
- `fork`、信号、`malloc`、套接字、线程和信号量的边界行为；
- 任何要在真实项目中使用的 API、调用约定或性能结论。

如果 C 和指针还不熟，先补 C 的数组、指针、结构体、动态内存与文件 I/O，再读第 2～3 章；只熟悉 Python 的读者尤其不要跳过这一步。

## 文本与版本说明

原 PDF 有内置文字层，因此这里不是重新 OCR，而是按物理页逐页导出。全文使用 UTF-8 保存，并以 `===== PDF 第 NNN 页 =====` 标记页码；页码报告覆盖 776 页。扫描文字层仍可能把代码空格、数学符号、上下标、表格和少数字符识别错误，精确引用必须对照 PDF。

本版反映的是约 2016 年的 x86-64、Linux、编译器和网络环境。二进制表示、缓存、链接、进程、虚拟内存与并发等核心模型仍然有效，但具体指令输出、工具参数、系统调用细节和 Web 技术会随平台变化。第 11 章偏 IPv4 与早期 HTTP 教学环境，不覆盖今天完整的 TLS、HTTP/2、HTTP/3 和云原生网络栈。
