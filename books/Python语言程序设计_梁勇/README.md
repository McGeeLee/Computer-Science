## 本书结构

全书采用“问题驱动、基础优先”的路径：先用小问题建立程序设计基本功，再进入面向对象，最后学习常见容器和递归。

```text
第一部分：程序设计基础       第1～6章
第二部分：面向对象程序设计   第7～13章
第三部分：数据结构和算法     第14～15章
```

目录中列出的第 16～23 章属于原书网站的附加章节，不在这份 467 页 PDF 中，也不在本次总结范围内。

## 推荐使用方式

可以先看总结，再按需要细读原书，但程序设计不能只靠阅读。建议每章按下面的闭环学习：

1. 用总结建立概念地图，知道这一章解决什么问题。
2. 亲手输入并运行两个代表性例子，不要只看运行结果。
3. 不看答案完成一个小练习，并主动测试边界输入。
4. 遇到语法、代码缩进、运算符或 API 细节时回到 PDF 核对。
5. 把错误原因和修改过程记入自己的 `notes/` 或代码实验中。

如果只想快速建立基础，优先掌握第 2、4、5、6、7、10、13、14、15 章。第 9 章的 Tkinter 适合用来理解事件驱动和 GUI 对象，但具体界面 API 可在实际需要时再查。

## OCR 与版本说明

原 PDF 是扫描件，没有文字层。OCR 全文以 UTF-8 保存，并使用 `===== PDF 第 NNN 页 =====` 标记物理页码。467 页全部完成识别，没有失败页，平均识别置信度约为 0.64。

普通中文段落整体可检索，但代码缩进、引号、括号、运算符、上下标、表格和图示可能识别错误。不要直接复制 OCR 中的代码运行；应回到 PDF 核对或重新输入。原书出版时间较早，个别开发环境、网址和 GUI 细节可能与当前环境不同，遇到版本问题时以当前 Python 文档和实际解释器行为为准。
