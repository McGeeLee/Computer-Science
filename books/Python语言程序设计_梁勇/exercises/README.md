# 章末编程题解答

本目录对应《Python语言程序设计》中文版第 1～15 章末尾的“编程题”。范围以仓库中
467 页 PDF 的题号为准，不包含需要访问旧网站的在线测试题，也不重复每节中的“检查点”。

## 使用原则

1. 先独立完成，再把这里当作答案和测试参考；直接抄写代码不能形成调试能力。
2. 解答使用现代 Python 3，核心计算尽量写成纯函数，方便测试和复用。
3. 书中使用 `eval(input(...))` 的地方改为明确的 `int`、`float` 或解析函数，避免执行任意输入。
4. Turtle 和 Tkinter 题保留为显式调用的绘图函数，导入模块时不会自动打开窗口。
5. OCR 对公式、负号、坐标和代码缩进识别不可靠；答案以 PDF 页面视觉核对结果为准。

## 运行

在本目录执行：

```bash
python3 -m unittest discover -s tests -v
```

计算题可以直接导入章节模块。函数名与题号一一对应：

```python
from solutions.chapter10 import ex_10_20

solutions = ex_10_20()  # 八皇后的 92 个解
```

GUI/Turtle 题也按题号调用：

```python
from solutions.chapter15 import ex_15_33

ex_15_33(4)  # 显示 4 阶希尔伯特曲线
```

第 1 章另外提供了命令行入口：

```bash
python3 -m solutions.chapter01 1.18
```

关闭绘图窗口即可结束程序。
