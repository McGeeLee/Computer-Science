# 第3章：数学函数、字符串和对象

## 本章主线

本章扩大程序可以处理的对象：除了基本数值运算，还可以调用数学函数、处理字符和字符串，并开始使用“对象调用方法”的写法。

## 核心知识

- `math` 模块提供平方根、三角函数、指数、常量等经过封装的数学能力。调用函数时要注意参数的单位、定义域和返回类型。
- 字符串是字符序列。ASCII 只覆盖有限字符，Unicode 为不同语言和符号提供统一编码；`ord()` 和 `chr()` 在字符与编码值之间转换。
- 转义序列表示换行、制表、引号等特殊字符。字符串连接会生成新的字符串，而不会修改原字符串。
- `print()` 的 `end` 参数控制输出末尾，`str()` 把其他值转换成文本，便于组合和显示。
- 对象把数据与可执行的操作放在同一概念中，方法是通过对象调用的函数。这里先认识用法，第 7 章再系统学习如何定义自己的类。
- 格式化决定数字和字符串怎样呈现，包括小数位、科学记数法、百分数、宽度和对齐。显示格式与内部数据应分开理解。

## 为什么这一章重要

真实程序很少只做裸算术。它们需要调用已有模块、理解文本编码、把结果转换成人能读懂的形式。学会查找和组合现成函数，是从“自己写每个步骤”迈向“利用抽象构建程序”的第一步。

## 容易混淆

- 角度与弧度不是同一个单位。
- 一个字符在 Python 中仍然是长度为 1 的字符串。
- 数字 `12` 与字符串 `"12"` 的类型和可用操作不同。
- 格式化产生的是文本表示，不应拿格式化后的字符串继续做数值计算。
- OCR 对引号、反斜杠和格式说明符容易识别错误，示例代码必须对照 PDF。

## 最小练习

读取姓名、金额和百分比，完成计算后输出一行对齐良好、包含货币和百分比格式的报告；再用 `ord()`、`chr()` 验证几个中英文字符的编码行为。

## 检查点速答（3.1～3.32）

- **数学函数（3.1～3.8）**：`sqrt(4)=2`、`sin(2π)≈0`、`cos(2π)=1`、`log(e)=1`、`exp(1)=e`；`ceil(-2.5)=-2`、`floor(-2.5)=-3`、`abs(-2.5)=2.5`。Python 的 `round(3.5)=4`、`round(-2.5)=-2`，体现了恰好一半时舍入到偶数的规则。
- **角度与弧度**：三角函数接收弧度；47° 应写成 `math.radians(47)`，`π/7` 转角度用 `math.degrees(math.pi / 7)`。输入单位错误通常不会报错，却会造成逻辑错误。
- **字符与字符串（3.9～3.17）**：`ord()` 把字符变成 Unicode 码点，`chr()` 做反向转换；因此 `chr(ord('A') + 3)` 是 `'D'`，`ord('Z') - ord('A')` 是 `25`。`\n`、`\t`、`\\` 等是转义序列，`\uXXXX` 可表示 Unicode 字符。
- **类型决定运算**：`2 + 3` 得数值 `5`，`"2" + "3"` 得字符串 `"23"`；字符串与整数不能直接相加，应先明确要做数值计算还是文本连接，再用 `str()`、`int()` 或 `float()` 转换。
- **对象与方法（3.18～3.22）**：对象有类型、标识和值，变量保存对对象的引用；`id()` 查看标识，`type()` 查看类型。字符串的 `lower()`、`upper()`、`strip()` 等方法返回新字符串，不修改原字符串。
- **格式化（3.23～3.27）**：格式化返回字符串；宽度是最小宽度而不是截断上限，`f` 表示定点小数，`e` 表示科学计数法，`%` 表示百分比，`<`/`>` 控制左右对齐。格式化只改变显示，不改变原数值。
- **Turtle 补充（3.28～3.32）**：`goto()` 定位，`dot()` 画点，`circle(50, steps=4)` 可画近似正方形；`speed()` 控制速度，`undo()` 撤销，`begin_fill()`/`end_fill()` 填充封闭区域，`hideturtle()` 隐藏光标。
