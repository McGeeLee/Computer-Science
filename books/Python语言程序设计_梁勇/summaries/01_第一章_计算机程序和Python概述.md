# 第1章：计算机、程序和 Python 概述

## 本章回答什么

这一章先建立程序运行的背景：计算机由哪些硬件组成，操作系统做什么，程序设计语言为什么存在，以及怎样创建、运行和检查一个最小的 Python 程序。

## 核心知识

- CPU 执行指令，内存保存正在使用的数据和程序，持久数据进入存储设备，输入输出设备让系统与外界交互。
- 机器语言最接近硬件，汇编语言用助记符表达指令，高级语言把程序员从具体机器细节中解放出来；解释器或编译系统再把代码转换成机器可执行的工作。
- 操作系统管理硬件资源、文件、设备和任务，为应用程序提供稳定的运行环境。
- Python 程序由语句、表达式、标识符和缩进结构组成。最小学习闭环是“编辑源文件 → 运行 → 观察结果 → 修改”。
- 注释、空白、命名和一致的格式不会改变算法，却直接影响程序能否被人理解和维护。

## 三类错误

- 语法错误：代码不符合语言规则，通常在运行前或刚开始运行时被发现。
- 运行时错误：语法正确，但执行到某一步发生非法操作，例如除零或文件不存在。
- 逻辑错误：程序能够运行，却给出错误结果，往往最难发现。

错误不是编程之外的意外，而是开发流程的一部分。看到错误信息时，应先找错误类型和位置，再缩小复现条件，而不是盲目改代码。

## Turtle 的作用

Turtle 把命令直接变成可见图形，让“状态、顺序和参数”变得直观：海龟的位置与朝向是状态，移动和转向会按顺序改变状态，颜色和距离则是参数。它为后面的选择、循环和函数提供了可观察的实验环境。

## 学完应能做到

独立创建并运行一个 `.py` 文件；解释代码、解释器、操作系统和硬件之间的关系；看到错误时先判断它属于语法、运行时还是逻辑问题；用 Turtle 画出由若干线段组成的图形。
