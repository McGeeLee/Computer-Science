# 第1章：计算机、程序和 Python 概述

## 本章回答什么

这一章先建立程序运行的背景：计算机由哪些硬件组成，操作系统做什么，程序设计语言为什么存在，以及怎样创建、运行和检查一个最小的 Python 程序。

## 核心知识

- CPU 执行指令，内存保存正在使用的数据和程序，持久数据进入存储设备，输入输出设备让系统与外界交互。
- 机器语言最接近硬件，汇编语言用助记符表达指令，高级语言把程序员从具体机器细节中解放出来；解释器或编译系统再把代码转换成机器可执行的工作。
- 操作系统管理硬件资源、文件、设备和任务，为应用程序提供稳定的运行环境。
- Python 程序由语句、表达式、标识符和缩进结构组成。最小学习闭环是“编辑源文件 → 运行 → 观察结果 → 修改”。
- 注释、空白、命名和一致的格式不会改变算法，却直接影响程序能否被人理解和维护。

## 三类错误

- 语法错误：代码不符合语言规则，通常在运行前或刚开始运行时被发现。
- 运行时错误：语法正确，但执行到某一步发生非法操作，例如除零或文件不存在。
- 逻辑错误：程序能够运行，却给出错误结果，往往最难发现。

错误不是编程之外的意外，而是开发流程的一部分。看到错误信息时，应先找错误类型和位置，再缩小复现条件，而不是盲目改代码。

## Turtle 的作用

Turtle 把命令直接变成可见图形，让“状态、顺序和参数”变得直观：海龟的位置与朝向是状态，移动和转向会按顺序改变状态，颜色和距离则是参数。它为后面的选择、循环和函数提供了可观察的实验环境。

## 学完应能做到

独立创建并运行一个 `.py` 文件；解释代码、解释器、操作系统和硬件之间的关系；看到错误时先判断它属于语法、运行时还是逻辑问题；用 Turtle 画出由若干线段组成的图形。

## 检查点速答（1.1～1.42）

- **硬件基础（1.1～1.10）**：计算机系统由硬件和软件共同组成；主要硬件是 CPU、内存、存储设备、输入设备和输出设备。CPU 执行指令，时钟速度常用 Hz/GHz 表示；1 bit 是一个二进制位，8 bit = 1 byte。RAM 可按地址直接访问但断电丢失，磁盘等存储设备用于长期保存。
- **程序设计语言（1.11～1.18）**：机器语言由二进制指令组成，汇编语言用助记符表示指令，高级语言更接近人的表达。汇编器翻译汇编代码；解释器边翻译边执行；编译器通常先把整个源程序转换为目标程序。程序员编写的是源代码。
- **操作系统（1.19～1.21）**：操作系统控制和协调硬件、文件、设备与应用程序。多道程序让多个任务共享 CPU；多线程让一个程序内的多条执行路径并发推进；多处理利用多个处理器或核心真正并行工作。
- **Python 与运行方式（1.22～1.34）**：Python 通常通过解释器执行；Python 2 与 Python 3 并非完全兼容。本书使用 Python 3。交互模式适合即时试验，脚本模式把代码保存为 `.py` 文件后重复运行；Python 区分大小写，以 `#` 写单行注释。表达式 `3.5 * 4 / 2 - 2.5` 的结果是 `4.5`。
- **错误分类（1.35～1.37）**：语法不合法产生语法错误；执行中遇到非法操作产生运行时错误；程序能运行但答案不对是逻辑错误。错误信息首先帮助定位前两类，逻辑错误还需要测试和推理。
- **Turtle（1.38～1.42）**：先 `import turtle`；`write()` 写字，`forward()` 前进，`color()` 改颜色，`penup()`/`pendown()` 控制是否留下轨迹，`goto()` 移到坐标，`circle()` 画圆，`done()` 保持绘图窗口。命令的先后顺序会持续改变海龟状态。
