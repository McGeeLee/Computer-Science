# 第10章：列表

## 本章主线

列表把任意数量的有序元素放入一个容器，使程序可以统一完成遍历、更新、统计、查找和排序。它是从处理几个独立变量迈向处理数据集合的关键。

## 核心知识

- 列表有顺序、可变、允许重复。下标访问单个元素，切片产生一段序列。
- `len`、`min`、`max`、`sum` 等函数提供常见聚合，列表方法负责添加、插入、删除、反转和排序。
- `for` 循环直接遍历元素；需要位置时再遍历下标或使用合适的枚举方式。
- 列表解析适合简洁地表达“遍历、筛选、转换”，但嵌套过深时普通循环更清楚。
- `split()` 把文本拆成列表，使文本输入能够进入统一的数据处理流程。
- 把列表传给函数可以处理任意长度数据；函数既可返回新列表，也可原地修改传入列表，接口必须说清楚。

## 复制与共享引用

简单赋值通常让两个名称引用同一个列表，一个位置的修改会从另一个名称看到。真正复制外层列表需要显式复制操作；如果元素本身也是可变对象，浅复制仍会共享内部对象。第 11 章的二维列表尤其容易遇到这个问题。

## 查找与排序

- 线性查找逐个检查，无需预先排序，最坏检查全部元素。
- 二分查找每次排除一半范围，但前提是数据已经按同一规则排序。
- 选择排序反复选择剩余最小值，插入排序把新元素插入已经有序的前缀。它们适合学习算法过程，并不意味着实际项目应放弃 Python 内置排序。

## 最小练习

读取一组数字，完成统计、去除一个指定值、排序和二分查找。分别实现返回新列表和原地修改两个版本，并通过 `id` 或修改实验说明引用是否共享。

## 检查点速答（10.1～10.25）

- **创建、访问和修改（10.1～10.4）**：空列表是 `[]`，三个元素可写 `[1,32,2]`。对 `[30,1,12,14,10.0]`，长度为 5，首尾下标是 0 和 4，`lst[2]=12`、`lst[-2]=14`。`append` 追加，`insert` 插入，`extend` 拼入多个元素，`remove` 删除首个匹配值，`pop` 删除并返回指定位置，`sort` 原地排序，`reverse` 原地反转，`shuffle` 的具体结果不确定。
- **运算与解析（10.5～10.8）**：`+` 连接列表，`*` 重复列表，`list1[1:3]` 取半开切片。解析式 `[x for x in range(0,10,2)]` 得 `[0,2,4,6,8]`，`[x for x in range(10,0,-2)]` 得 `[10,8,6,4,2]`。列表可混合类型、大小可变、允许重复并可按下标访问。
- **共享与复制（10.9～10.16）**：`list2 = list1` 共享同一列表，所以把 `list1[0]` 改为 22 后两者都是 `[22,43]`；解析式复制或 `list1.copy()` 产生独立外层列表。访问越界下标抛出 `IndexError`。循环依次执行 `lst[i] = lst[i-1]` 会让后续元素都被前一个更新值覆盖。
- **字符串转列表与常用模板（10.11～10.14）**：`list("welcome")` 得字符列表，`"welcome".split("o")` 得 `["welc","me"]`。100 个假值可写 `[False] * 100`；末项是 `lst[-1]`，前五项和为 `sum(lst[:5])`，随机元素可先在 `range(len(lst))` 中生成合法下标。
- **函数参数（10.17～10.19）**：传列表不会自动创建副本。函数若只把形参重新绑定到新列表，调用者不变；若修改元素，调用者可见。可变默认列表会跨调用共享：示例连续两次删除 1 会依次得到 `[1,2,3]` 和 `[2,3]`；用 `None` 后每次新建，则两次都得到 `[1,2,3]`。
- **查找（10.20～10.21）**：在有序表 `[2,4,7,10,11,45,50,59,60,66,69,70,79]` 中，二分查找 10 命中下标 3；12 不存在，插入点是下标 5。若本书的二分函数返回 `-4`，表示未找到，并编码了插入位置 3。
- **排序（10.22～10.25）**：`[3.4,5,3,3.5,2.2,1.9,2]` 经选择或插入排序后都是 `[1.9,2,2.2,3,3.4,3.5,5]`。选择排序改降序时每轮选最大值；插入排序改降序时反转移动条件，让较大元素进入已排序前缀的前部。
