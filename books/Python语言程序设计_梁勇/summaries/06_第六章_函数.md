# 第6章：函数

## 本章主线

函数把一段有明确职责的计算封装起来。它既是复用代码的工具，也是分解问题、隐藏细节和建立抽象边界的主要方法。

## 核心知识

- 定义函数时写形参，调用函数时传实参。位置参数按位置对应，关键字参数明确指出名称。
- 有返回值的函数计算并交回结果；不以结果为目的的函数通常执行显示、修改界面等动作。`return` 会立即结束当前函数。
- Python 传递的是对象引用的值。函数内重新绑定形参，不会自动改变调用者的变量；如果传入可变对象并修改其内容，调用者可能观察到变化。
- 局部变量只在函数内部有效；模块级变量虽然可访问，但过度依赖会制造隐藏耦合。
- 默认参数为常见情况提供简洁调用；返回多个值在 Python 中通常通过元组实现。
- 模块把相关函数放入独立文件，形成可复用接口。

## 函数抽象

调用者应主要关心函数“需要什么、返回什么、可能产生什么副作用”，不必掌握每行实现。设计时可先写出主流程和函数名称，再逐步求精每个子问题。好的函数通常职责单一、名称明确、参数少而必要、返回值稳定。

## 容易混淆

- `print()` 结果与 `return` 结果不同：前者显示给人，后者交给调用者继续计算。
- 函数没有显式 `return` 时会返回 `None`。
- 默认参数只适合真正合理的默认行为；可变默认值在现代 Python 中尤其容易产生跨调用共享状态的问题。
- 为了“少写函数”而复制代码，通常会增加后续修改和测试成本。

## 最小练习

把前几章的一个完整程序重构成三个层次：输入与校验、纯计算函数、输出格式化。为纯计算函数准备若干直接调用的测试，不依赖键盘输入。

## 检查点速答（6.1～6.27）

- **定义与调用（6.1～6.7）**：函数通过 `def 名称(形参):` 定义，通过名称加实参调用。它减少重复、分解问题、隐藏实现并便于独立测试；较短的求最大值函数可以用条件表达式简化，但清晰度优先。
- **返回值**：只产生动作的函数可不写返回值，此时结果是 `None`；`return` 可返回一个值并立即结束函数，也可单独写来提前结束。有返回值的调用能出现在表达式中，只执行显示的函数通常作为语句调用。
- **参数检查（6.8～6.13）**：实参数量必须与接口匹配。位置参数按顺序绑定，关键字参数按名称绑定；位置参数必须写在关键字参数之前。全部使用关键字参数时，书写顺序可以不同。
- **对象引用与作用域（6.14～6.20）**：Python 调用函数时把对象引用绑定给形参。对整数、字符串等不可变对象重新赋值不会改变调用者变量；修改传入可变对象的内部内容则可能被调用者看到。形参与实参同名没有冲突，局部名称在函数外不可用。
- **默认参数（6.21～6.23）**：带默认值的参数必须位于必需参数之后；调用时省略它就采用默认值。不要把可变列表等对象直接设为默认值，否则多次调用可能共享状态；使用 `None` 再在函数内部新建对象更安全。
- **多个返回值与随机字符（6.24～6.26）**：`return a, b, c` 实际返回元组，可用多个变量解包。若函数返回两数的和、差、积、商，输入 `9,5` 得 `14,4,45,1.8`。闭区间整数用 `randint`，字符可在 `ord()` 与 `chr()` 之间随机选码点，浮点区间用起点加 `random()*跨度`。
- **抽象与逐步求精（6.27）**：调用者只依赖函数契约，把实现视作黑箱；设计者从主问题开始逐层拆成可测试的小函数，直到每个函数职责足够简单。
