# 第8章：更多字符串和特殊方法

## 本章主线

本章一方面把字符串当作完整的序列类型深入学习，另一方面通过特殊方法说明：自定义对象也可以参与 Python 熟悉的运算和显示方式。

## 字符串操作地图

- 构造与长度：创建字符串，使用 `len()`、`min()`、`max()`。
- 访问与截取：下标访问一个位置，切片取得子串；负下标和越界规则应通过实验掌握。
- 组合与成员关系：`+`、`*`、`in`、`not in`。
- 检查：字母、数字、空白、大小写和合法标识符等测试方法。
- 搜索与统计：前缀、后缀、查找位置、反向查找和出现次数。
- 转换与清理：大小写转换、替换、去除两侧空白。
- 对齐与格式化：将文本放入固定宽度或模板中。

字符串不可变。看似“修改字符串”的方法通常返回一个新字符串，原值不会改变。连续执行多步清理时，要保存每一步返回的结果。

## 特殊方法与运算符重载

Python 的许多语法会转化为对象的特殊方法调用。为类实现适当的特殊方法后，自定义对象可以被打印、比较或参加算术运算。书中的 `Rational` 类用分子与分母表示有理数，并让加减乘除表现得像普通数值。

运算符重载应保持直觉和代数含义。如果 `+` 被赋予令人意外的副作用，代码会更难理解。还要保持不变量，例如分母非零、符号位置统一、分数约分。

## 最小练习

先写一个规范化用户输入的字符串处理流水线，再设计一个简单的二维点或分数类，实现清晰的字符串表示和一种合理运算。测试空串、找不到子串和非法构造参数。
