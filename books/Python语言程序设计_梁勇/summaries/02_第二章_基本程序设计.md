# 第2章：基本程序设计

## 本章主线

第 1 章解决“怎样运行程序”，本章开始解决“怎样把一个计算问题写成程序”。基本模型是：读取输入，把值保存在变量中，用表达式计算，再按要求输出结果。

## 核心知识

- `input()` 读取文本；需要数值运算时，应使用 `int()` 或 `float()` 转换，并考虑输入不合法的情况。
- 变量是名称与值之间的绑定。赋值语句先计算右侧，再把结果赋给左侧；`x = x + 1` 是更新，不是数学等式。
- 标识符应表达含义，命名常量用于说明在程序运行中不应随意变化的值。
- Python 支持同时赋值，这既可一次设置多个变量，也能安全交换两个值。
- 数值类型、`+ - * / // % **`、运算符优先级和括号共同决定表达式的结果。`/`、`//` 与 `%` 的含义尤其要通过正数和负数实验确认。
- 类型转换和四舍五入不是排版细节；它们可能改变数值和精度。

## 软件开发流程

一个可靠的小程序通常经历：明确需求 → 找出输入和输出 → 设计计算步骤 → 写代码 → 用正常值和边界值测试 → 修正。贷款计算、当前时间和两点距离等案例的意义，不在公式本身，而在演示怎样从问题说明得到变量和算法。

## 容易混淆

- `input()` 返回字符串，即使用户输入了数字。
- 浮点数是有限精度近似，不能假设每个十进制小数都能被精确表示。
- 格式化显示成两位小数不等于内部值已经永久变成两位小数。
- 一个长表达式即使语法正确，也可能因优先级理解错误而得到错误结果；不确定时加括号。

## 最小练习

写一个单位换算或贷款计算器：先列出输入、输出和公式，再实现程序。至少测试普通值、零、极小值和不合理值，并说明程序当前如何处理它们。

## 检查点速答（2.1～2.21）

- **表达式与输入**：`width = 5.5; height = 2` 的面积是 `11.0`；100 英里乘 `1.609` 得 `160.9` 千米。`input()` 返回字符串，现代写法应按需要使用 `int(input())` 或 `float(input())`，不建议照搬书中的 `eval(input())`。
- **标识符与赋值**：名称可含字母、数字和下划线，但不能以数字开头、不能是关键字且区分大小写。`2 = a` 的左侧不是可赋值目标；`x = y = z = 0` 可同时初始化，`a, b = b, a` 可交换变量。
- **数值运算**：`42 / 5 = 8.4`、`42 // 5 = 8`、`42 % 5 = 2`，而 `40 % 5 = 0`；`45 + 4 * 4 - 2 = 59`，`5 ** 2 = 25`。星期二后第 100 天向后偏移 `100 % 7 = 2` 天，即星期四。
- **增量赋值**：若每小题都从 `a = 1` 开始，则 `a += 4`、`a -= 4`、`a *= 4`、`a /= 4`、`a //= 4`、`a %= 4` 分别得到 `5`、`-3`、`4`、`0.25`、`0`、`1`。增量赋值仍然是先计算再重新绑定。
- **转换与舍入**：`int()` 截去小数部分并返回新整数，不会修改原对象；`int("04")` 为 `4`，`int("4.5")` 抛出 `ValueError`。`round()` 采用 Python 的舍入规则，遇到恰好一半时要注意“舍入到偶数”等行为。
- **时间与开发过程**：Unix 时间以 1970-01-01 00:00:00 UTC 为纪元，`time.time()` 返回距纪元的秒数；当前分钟内的秒数可用 `int(time.time()) % 60`。程序设计应经过需求、分析、设计、实现、测试和维护，并先明确输入—处理—输出。
