# Computer Science Reading Library

一个持续积累的计算机科学读书仓库。这里不限定某一本书：每本书拥有独立目录，用来保存原始资料、可检索文本、章节总结和后续深入笔记。

> 仓库保持私有，主要用于个人学习。收录资料的著作权仍归各自权利人所有；除非明确拥有授权，请勿把包含完整书籍或 OCR 全文的仓库改为公开。

## 目录约定

```text
books/
└── 书名或书名_版本/
    ├── README.md          # 书籍索引、阅读路线和完成状态
    ├── source/            # PDF、EPUB 等原始资料
    ├── text/              # OCR 或其他可检索文本
    ├── summaries/         # 全书与章节总结
    └── notes/             # 按主题积累的深入笔记，可选
```

新书可以从 [`books/_template`](books/_template/README.md) 开始建立目录。详细规则见 [`books/README.md`](books/README.md)。

## 推荐整理流程

1. 保存原始资料并记录书名、版本和来源信息。
2. 对扫描资料执行 OCR，保留原始页码映射和识别质量说明。
3. 先写全书导读，再按章节总结核心问题、概念关系和容易误解处。
4. 阅读或实际使用时，再增加专题笔记、例题、代码实验和外部资料。
5. 定期更新根目录书目，让仓库始终可以作为总索引使用。

## 总结的定位

章节总结用于快速建立知识地图，并不替代原书。出现以下情况时，应回到原文或其他权威资料：

- 需要精确定义、公式、证明或原话引用；
- 总结中的论证不足以回答当前问题；
- 观点与今天的技术环境可能已经不一致；
- 准备把知识用于项目、研究或重要决策。
