## 容易误导学习的字幕

| 字幕现象 | 正确理解 |
| --- | --- |
| “缺课学期” | 课程名是 **The Missing Semester**，这里称“计算机教育中缺失的一课” |
| 把 Bash 译为“批处理” | Bash 是一种 Shell；与 Windows 批处理环境分开理解 |
| “美元路径”、小写 path | `PATH` 是变量名；`$PATH` 表示取它的值；它与某个文件的路径是不同概念 |
| “唯一命令”、unique | 命令名是 `uniq`，只合并相邻的重复行 |
| sed 的“-g 参数” | `g` 是替换表达式中的标志，如 `s/old/new/g` |
| “ark”“auc”“oc”“arc” | 该段讲的是 `awk` |
| “sikh”“c” | 命令替换示例中指的是 `seq` |
| “-dash x sec”“ex” | 文件查找段讲的是 `find` 的 `-exec` 选项 |
| “W 代表向右” | 文件权限中的 `w` 表示写；`r` 表示读，`x` 表示执行 |
| `--help`、`{}`、`\;` 等符号被转成普通文字 | 从可靠命令示例核对符号，不按字幕音译拼命令 |

## 讲解时补充的边界

- `cd` 是 Shell 内置命令，它改变当前 Shell 的工作目录。`if` 是语法关键字，`|` 是操作符。
- `echo` 在 Bash / Zsh 中通常是内置命令；不能把所有命令都解释成从 `PATH` 中找到的外部程序。
- `test -f` 检查路径存在且为普通文件；任意路径是否存在可使用 `test -e`。
- shebang 指定直接执行脚本时采用的解释器。用 `bash script.sh` 时由显式指定的 Bash 读取脚本。
- `awk -F,` 适合简单逗号分隔文本；带引号、字段内逗号或换行的完整 CSV 应交给 CSV 解析器。
- macOS 的 BSD 工具与 Linux 上常见 GNU 工具有差异，例如 `sed -i` 的参数形式；笔记优先用不改原文件的示例。
