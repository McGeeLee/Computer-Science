## 讲解时补充的边界

- `cd` 是 Shell 内置命令，它改变当前 Shell 的工作目录。`if` 是语法关键字，`|` 是操作符。
- `echo` 在 Bash / Zsh 中通常是内置命令；不能把所有命令都解释成从 `PATH` 中找到的外部程序。
- `test -f` 检查路径存在且为普通文件；任意路径是否存在可使用 `test -e`。
- shebang 指定直接执行脚本时采用的解释器。用 `bash script.sh` 时由显式指定的 Bash 读取脚本。
- `/bin/sh` 的实现因系统而异。使用 Bash 语法的脚本明确选择 Bash，不能仅凭 `/bin/sh` 这个路径判断为 Bash。
- `awk -F,` 适合简单逗号分隔文本；带引号、字段内逗号或换行的完整 CSV 应交给 CSV 解析器。
- macOS 的 BSD 工具与 Linux 上常见 GNU 工具有差异，例如 `sed -i` 的参数形式；笔记优先用不改原文件的示例。
