## 已讨论的知识点 · 2026-10-04

- 第一课前半段的主线：课程动机、Terminal / Shell、命令与参数、路径、程序查找和基础文本工具。
- IAP 的全称、MIT 一月自主活动期，以及本课程与 IAP 2026 的关系。
- Bash 的全称 Bourne-Again SHell 与名称双关；Zsh 的名称和交互功能。
- Shell 是类别，Bash / Zsh / PowerShell 是并列的具体实现，Terminal 提供交互窗口。
- `~` 与主目录；提示符 `$`、`#`、`%` 的常见约定；`$HOME` 中的 `$` 属于变量展开。
- 提示符可自定义；用 `id -u` 查看有效用户 ID；root 用户与 `/` 根目录属于不同概念。
