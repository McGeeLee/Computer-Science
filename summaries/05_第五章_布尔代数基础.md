# 第五章：布尔代数基础

## 本章地位

第五章既提供数字逻辑所需的布尔代数入门，也作为前面“形式化、构造性方法、公理化方法”的实际示范。学习重点不是机械记忆等式，而是理解怎样从定义和少量规则建立一个可推演的形式系统。

## 1. 集合与基本运算

集合把具有某种共同条件的对象作为整体研究。需要区分：

- 元素属于集合，与一个集合包含另一个集合；
- 空集与只包含空集的集合；
- 并、交、补、差等运算；
- 集合相等、包含和运算之间的关系。

集合可以通过外延枚举元素，也可以通过内涵描述元素必须满足的性质。面对无穷集合时，内涵和构造性描述尤其重要。

## 2. 从集合运算到布尔代数

布尔代数研究具有两种基本值或两个对偶状态的代数结构。集合的并、交、补，命题的或、与、非，以及数字电路中的逻辑门，在适当解释下都可以满足相似的代数规律。

这说明同一个形式系统可以拥有不同模型：符号和公理保持不变，符号所指的对象可以是集合、真假命题或电路状态。形式化的价值就在于，一次证明可以迁移到多个具体领域。

## 3. 公理系统与对偶性

公理系统从少量原始概念和基本关系出发，通过规定的推理规则推出其他定理。评价一个公理系统通常要关心：

- 一致性：不能同时推出互相矛盾的结论；
- 独立性：某条公理不能轻易由其他公理推出；
- 完备性：希望系统能够推出目标领域内所需的全部有效结论；
- 简洁性：基本概念和公理尽可能少而清楚。

布尔代数的对偶性意味着在相应表达式中交换两种运算和两个基本值，可以得到另一条对应关系。它既能减少重复证明，也揭示了系统结构中的对称性。

## 4. 等式推演与化简

布尔表达式可以根据公理和已经证明的定理逐步变换。每一步都必须说明使用了什么规则，这与代数化简、程序变换和形式证明具有相同思想。

在数字电路中，等价表达式实现相同逻辑功能，但所需逻辑门数量、延迟和成本可能不同。因此布尔化简同时体现：

```text
语义保持不变 + 表示形式得到优化
```

这一思想会在编译优化、数据库查询优化和程序重构中反复出现。

## 5. 标准形式与完备性

标准形式把任意布尔表达式转换为结构统一的形式，使比较、判定和自动处理更容易。它说明复杂表达式可以由有限种基本结构组合表示，也为数字电路综合和逻辑推理提供机械化方法。

这里的“完备”不能只凭直觉理解为“内容很多”，而是需要相对于给定语言和语义说明：系统的推导能力是否覆盖所有目标有效式。

## 学习建议

1. 先在集合、命题和电路三个模型之间建立对应关系。
2. 每个等式都尝试用真值表和代数推导两种方式验证。
3. 推导时逐行标注使用的公理或定理。
4. 公式和符号必须回到原 PDF 核对，OCR 文本不能作为第五章的精确公式来源。
5. 最终目标是理解公理、模型、语义、证明和实现如何构成一个整体。
